# Contributing

We welcome contributions to this codebase. We expect all contributors to be respectful and kind in their interactions with the maintainers and other users. We welcome all contributors no matter their race, age, gender identity, sexual orientation, etc.

## PR requirements
Please run all `./test-all` in the Nix shell and confirm it passes. Please add test coverage for nontrivial additions of bugfixes.

## LLM/AI usage
Please explicitly note the level of LLM usage in your contribution; there's no shame involved, this project has been largely vibecoded. We expect contributors to avoid LLM usage when communicating directly with maintainers (usages like translation of human languages excepted). If we ask a question, we're asking a person, not a machine.
